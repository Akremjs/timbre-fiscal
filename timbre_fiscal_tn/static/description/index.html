Droit de Timbre Fiscal (Tunisie)

Facturation conforme à la réglementation tunisienne

Fonctionnalités

  • Ajout automatique du timbre fiscal sur les factures clients
  • Montant configurable (par défaut 1,000 DT)
  • Libellé propre « Timbre Fiscal » sur la facture
  • TVA exclue sur la ligne timbre
  • Compatible Odoo 17 et localisation Tunisie

Installation

Aucune configuration complexe : installez le module, créez une facture client et la ligne timbre est ajoutée automatiquement.

Configuration avancée

Paramètres système (mode développeur) :

  • timbre_fiscal_tn.amount — montant du timbre
  • timbre_fiscal_tn.on_customer_invoice — factures clients
  • timbre_fiscal_tn.on_vendor_bill — factures fournisseur
