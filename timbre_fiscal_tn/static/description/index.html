Droit de Timbre Fiscal (Tunisie)

Automatisez le timbre fiscal sur vos factures clients Odoo 17

Conforme à la réglementation tunisienne — installation en un clic, sans saisie manuelle.

Le problème que ce module résout

En Tunisie, les factures clients doivent inclure le droit de timbre fiscal (généralement 1,000 DT). Sans automatisation, chaque facture exige une ligne saisie à la main — source d'oublis, d'erreurs de montant et d'écarts comptables.

Ce module ajoute automatiquement la ligne « Timbre Fiscal » sur chaque facture client en brouillon, avec le bon montant et sans TVA, directement intégrée au total de la facture.

Aperçu sur facture

Exemple réel : la ligne timbre apparaît proprement sous les articles, avant le total.

Fonctionnement

Automatique

  • À la création ou modification d'une facture client en brouillon, le module ajoute la ligne timbre.
  • Libellé clair sur le PDF : « Timbre Fiscal » (sans code article visible).
  • Quantité fixe : 1 — montant par défaut : 1,000 DT.
  • La ligne est exclue de la TVA.

Intelligent

  • Ne duplique pas la ligne si elle existe déjà.
  • Met à jour le montant si vous changez le paramètre système.
  • Retire la ligne si le timbre est désactivé sur la facture.
  • Par défaut, pas de timbre sur les factures fournisseur.

Installation

  1. Installez le module depuis Apps (ou copiez le dossier dans vos addons).
  2. Mettez à jour la liste des applications.
  3. Cliquez sur Installer — aucune configuration obligatoire.
  4. Créez une facture client : la ligne timbre est ajoutée automatiquement.

C'est tout. Le produit « Timbre Fiscal » et les paramètres par défaut sont créés à l'installation.

Configuration (optionnelle)

Mode développeur → Paramètres → Paramètres techniques → Paramètres système :

Clé Description Défaut
timbre_fiscal_tn.amount Montant du timbre en dinars 1.0
timbre_fiscal_tn.on_customer_invoice Activer sur les factures clients True
timbre_fiscal_tn.on_vendor_bill Activer sur les factures fournisseur False

Sur chaque facture, le champ « Appliquer le timbre fiscal » permet d'activer ou de désactiver le timbre au cas par cas.
