Droit de Timbre Fiscal (Tunisie)

Module Odoo 17 — AKREM KHELIFI

Fonctionnalités

  • Ajout automatique du timbre fiscal sur les factures clients
  • Montant configurable (par défaut 1,000 DT)
  • Produit service dédié AKREM_TF
  • Exclusion de la TVA sur la ligne timbre
  • Compatible localisation tunisienne (l10n_tn)

Configuration

Paramètres système :

  • akrem_timbre_fiscal.amount — montant du timbre
  • akrem_timbre_fiscal.on_customer_invoice — activer sur factures vente
  • akrem_timbre_fiscal.on_vendor_bill — activer sur factures achat
